# 第一阶段：不要改 ChatGPT，本地做“工具代理层”

这是关键。

不要试图修改 ChatGPT 网页。

原因：

网页 AI 本身不是 Agent Runtime。

它只是：

```
用户
 ↓
模型
 ↓
文本输出
```

而 Harness 是：

```
模型
 ↓
工具选择
 ↓
工具执行
 ↓
结果回传
 ↓
继续推理
```

DeepSeek Harness 的设计本身就是把工具、Session、Loop、插件组合成 Agent Runtime。([GitHub][2])

所以应该让：

```
ChatGPT
    |
    |
你的 Bridge
    |
    |
DeepSeek Harness
```

成为：

ChatGPT = 大脑
Harness = 手脚

# 第二阶段：建立统一 Tool API

建议设计一个自己的协议：

例如：

## Tool Manifest

```json
{
"name":"open_project",
"description":"打开Android项目",
"parameters":{
"path":"string"
}
}
```

然后你的 Gateway 自动转换：

### 给 AI 看：

```
你拥有以下工具：

open_project()
run_terminal()
read_file()
adb_install()
docker_restart()
```

---

AI 输出：

```json
{
"tool":"adb_install",
"args":{
"apk":"app-release.apk"
}
}
```

Gateway 接收：

↓

调用 Harness:

```
tool.call(
 adb_install
)
```

↓

返回：

```
安装成功
```
