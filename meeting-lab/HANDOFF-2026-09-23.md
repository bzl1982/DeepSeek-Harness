## 5. UI 代码定式（改 CSS/JS 前必读，避免重蹈覆辙）

- **网格自适应**：`.grid{grid-auto-rows:minmax(220px,1fr)}`，**删 `align-content:start`**，`.cell` **无 min-height**（行高 1fr 平分内部空间，窗口最大化即拉伸，无底部预留；最后一排不满时右空左不空，grid 自动左上摆放）。
- **放大 ⤢**：`toggleZoom(cell)` = `grid.prepend(cell)` + `.zoomed{grid-column:1/-1;grid-row:span 2}`，还原回原位（`cell._posNext`）。
- **拖高**：按 grid-row span N 步进（`dragCellHeight`），**禁止用 px 行内高度**覆盖 1fr。
- **列数**：`.seatctl #sel-cols` 下拉（3/4/5/6）→ `colsPerRow` → `relayout()`。
- **网页席位与 API 席位同 `.cell` 类**：`renderApiSeats()` 也要用 `.cell`（之前 API 扁是因为单独 `.apiseat` 无高度 + `.rz` 只在 zoom 显示——已修，别再分两套）。
- **顶部三块位置**：主持人栏 `.chairbar`（seatbar 之下、grid 之上）；参会名单 `#seat-chips`（renderSeatbar 渲染）；角色组 + 重排 + 每排窗口数在 `.seatctl`，紧挨 `#seat-chips`。
- **名字同步**：顶部勾选名单 = 底部名牌，均来自 `PROVIDERS`（9 网页）+ `getRedacted()`（API 候选）；API 名牌格式 `公司+模型+-API`（如 `深度求索-deepseek-chat-API`）。

## 6. 引擎接口（`transparent-meeting.js`）

```js
const tm = new TransparentMeeting({
  topic, participants, adapters, names,
  rules, rounds, outBaseDir, materials,   // materials: 议题资料文件数组，自动拷入会议文件夹
  perTurnTimeoutMs,                        // 默认 180000
});
await tm.run();                  // 每轮并发 speakTo，自动写 round-N.md + 会议记录.md
tm.pause(); tm.resume(); tm.abort();   // abort 抛 MEETING_ABORTED，已完成发言照常落盘
tm.pushChairMessage(text);       // 主持人发言进下一轮【主持人发言】块（kind:'chair'）
```

## 7. 已知坑 / 硬约束（致命级）

1. **disable-gpu 下 CDP 截图取不到帧** —— 验证 UI 用 `Runtime.evaluate` 读 DOM，别用 `Page.captureScreenshot`（会超时）。
2. **完成检测必须基于增量非存在**：已登录页面本就有内容（欢迎语/history/prompt 回显）→ 若「页面有非空文本」即判完成，Gemini 932ms / ChatGPT 1121ms 假完成。口诀：**存在 ≠ 新增**。
3. **Gemini 输入框是 Quill**，`sendInputEvent` 的 Enter 对其无效且不抛异常 → 文本卡输入框。修法：回车后校验 `composerFilled`，没清空就点页面发送按钮（`button[aria-label="发送"]`）。
4. **Electron 取文件真实路径**：`File.path` 已废弃 → 必须用 `webUtils.getPathForFile(file)`，且 contextIsolation 时该调用必须在 preload 里用 contextBridge 暴露（否则拿 undefined）。
5. **备份策略**：删 `backup/transparent-v1` 必须用户明确许可；当前第五轮改动未提交，回滚会丢。
6. **不碰 desktop/**：另一会话在改，本会话严禁动。
7. **咨询外部优先**（用户铁律）：自己 ≤2 轮无定论就写咨询案出去问多家（元宝/谷歌/千问/DP）；且「我自己写的论断」也得核过一手源头，否则会污染外部方案（教训：MAF 选型曾误读二手文一句话）。
8. **本机删除机制**：`rm -rf` 走 safe-delete 回收站不释放空间；删大目录用 PowerShell `robocopy $empty $target /MIR` 镜像清空再 `Remove-Item`；删前 `git ls-files` 确认是否被跟踪。
